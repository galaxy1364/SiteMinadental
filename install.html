نصب روی دستگاه

اگر مرورگر شما نصب PWA را پشتیبانی کند، گزینه نصب در منوی مرورگر یا نوار آدرس ظاهر می‌شود.

وضعیت نصب در همین دستگاه بررسی می‌شود.

حریم خصوصی PWA

صفحات عمومی می‌توانند برای دسترسی آفلاین cache شوند؛ مسیرهای API، Portal، Admin، Booking، config و داده‌های mutable از cache حساس خارج هستند.
