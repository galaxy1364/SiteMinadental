# Byte-exact Build Baseline Plan

This document authorizes no production change. It records the next safe operation only:

1. Create a separate branch from `main`.
2. Add the supplied compiled website files byte-for-byte.
3. Verify every Git blob SHA-1 and file SHA-256 against local evidence.
4. Open a Draft PR.
5. Do not merge, deploy, or modify appearance.

The baseline branch is an immutable deployment artifact, not recovered source code.
