# Advertising & Growth Architecture V4

Search / Maps / Instagram / Aparat / Referral → Campaign Landing → Call / WhatsApp / Booking / Assistant → Lead → MinaDent → Appointment → Attendance → Treatment → Payment → Offline Conversion.

## Browser
UTM، gclid، fbclid، first/last touch، consent و eventهای تماس، واتساپ، نقشه، فرم، جست‌وجو، تصمیم‌یار، دستیار و نوبت.

## Server
Meta Conversions API adapter، Marketing Webhook برای Google Data Manager/CRM، normalize و SHA-256 موبایل، event_id برای deduplication و secret سروربه‌سرور MinaDent.

## Campaigns
ایمپلنت، زیبایی، درمان ریشه، کودک و مراجعه فوری در منطقه ۲۲؛ بدون قیمت، Review یا نتیجه ساختگی.

## ممنوعیت
PII داخل dataLayer، Pixel بدون consent، token داخل VITE_*، تضمین رتبه یا درمان و Conversion ساختگی ممنوع است.
