این صفحه بین «کد موجود»، «قابلیت متصل و آزموده‌شده»، «اطلاعات تأییدشده مالک» و «Production evidence» تفاوت می‌گذارد. وجود UI یا کد به‌تنهایی به معنی عملیاتی بودن سرویس نیست.

هدف دامنه Production: —

Runtime / Operational Readiness

فرم‌های عملیاتیدر حال بررسیثبت واقعی فقط پس از Backend، validation سرور، anti-abuse و Evidence رفت‌وبرگشت مجاز است.
رزرو واقعیدر حال بررسیظرفیت، collision prevention، reschedule/cancel و confirmation باید server-side آزموده شوند.
OTP / احراز هویتدر حال بررسیProvider، rate limiting، recovery، abuse controls و AAL مناسب باید واقعی باشند.
پرداختدر حال بررسیموفقیت فقط با callback سرور، amount lock، idempotency و reconciliation معتبر است.
دامنه Productionدر حال بررسیDNS/Cloudflare/headers و smoke test مستقیم دامنه باید Evidence داشته باشند.

Owner Truth Gates

نشانی دقیق—بدون حدس یا geocoding ساختگی.
Map Pin—Google/Neshan/Balad فقط پس از Pin واقعی.
ساعات کاری—در UI و structured data فقط پس از تأیید.
تلفن / ایمیل—کانال عمومی تأییدنشده منتشر نمی‌شود.
مدارک / تجهیزات—Claim پزشکی باید سند و reviewer داشته باشد.
Reviews—نظر ساختگی یا بدون provenance ممنوع.
Before / After—فقط با فایل واقعی و consent قابل اثبات.

Evidenceهایی که هنوز جایگزین‌پذیر نیستند

  • VoiceOver / TalkBack / keyboard / zoom و تست واقعی دستگاه.
  • Core Web Vitals میدانی در صدک ۷۵ روی موبایل و دسکتاپ.
  • Cloudflare production headers/WAF/rate limiting و domain smoke test.
  • Backup/restore drill با RPO/RTO واقعی.
  • DAST و pentest مستقل روی محیط Production-like.
  • OTP، پرداخت و notification provider واقعی.
